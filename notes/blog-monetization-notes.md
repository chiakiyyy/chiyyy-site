## 1. 収益化の全体構造（考え方）

ブログ収益化は「集客記事」と「収益記事（キラーページ）」の役割分担で成り立つ、という整理が軸になっている。

| 記事タイプ | 目的 | chiyyy.comでの当てはめ候補 |
|---|---|---|
| 集客記事 | 検索流入でアクセスを集める（ロングテールキーワード） | 「お金・キャリア」「子育て・共働き」等の悩み解決記事 |
| まとめ記事（ハブ） | カテゴリ内の記事を束ねて回遊させる | 各カテゴリのトップ or 特集記事 |
| 収益記事（キラーページ） | 商品・サービスへの誘導、成約 | レビュー記事、比較記事（該当する場合） |

**示唆**: 個人日記ブログ（pregnancy-childbirth-parenting-priorities.md のような記事）は「集客記事」として機能させ、そこから関連するまとめ記事・収益記事へ内部リンクで誘導する設計にすると回遊率が上がる。現状は単発記事が多く、記事同士のつながりが弱い可能性がある。

## 2. キーワード選定の実践フロー（記事執筆に反映できる部分）

元記事のステップを、実際に記事を書く際のチェックリストとして再構成：

1. **想定読者の悩みを2〜3パターン言語化する**（例：「妊娠中の不安」「産後の家計不安」など）
2. **関連キーワードを洗い出す**（ラッコキーワード等のサジェストツールで実際の検索語を確認）
3. **検索ボリュームを確認し、月間10〜100程度のロングテール（3語以上）を狙う** — 個人ブログが上位表示を狙いやすい領域
4. **サイトのテーマ・カテゴリに合わないキーワードは除外する**
5. **実際に検索して上位サイトの顔ぶれを見る**（大手・専門メディアばかりなら回避、個人ブログが混じっていれば勝機あり）

**示唆**: 今後の記事タイトル決定時、「〜ランキング」のような曖昧な表現より、既に実践している「富山で妊娠・出産して分かった、漠然とした不安の乗り越え方」のような検索意図に寄せたタイトル修正の考え方は、この元記事の思想と一致している。今後もタイトル決定時に「読者が実際に検索窓に打ち込みそうな語句」を意識する。

## 3. SEO対策チェックリスト（サイト構造・記事の両面）

抽出した項目のうち、Astro製の静的サイトであるchiyyy.comに関連度が高いものを優先順位付け：

**すぐ確認できるもの**
- [ ] サイトマップが正しく生成・送信されているか（Astroのsitemap連携）
- [ ] 各記事にメタディスクリプションが設定されているか
- [ ] 画像のalt属性・ファイル名がわかりやすいか
- [ ] パーマリンク（URLスラッグ）が内容を表す英単語になっているか
- [ ] カテゴリ数が多すぎないか（5カテゴリは適正範囲）

**記事執筆時に意識するもの**
- [ ] タイトル・見出しに検索意図と一致するキーワードが入っているか
- [ ] 記事内に関連する他記事への内部リンクがあるか（孤立記事を作らない）
- [ ] 広告・アフィリエイトリンクを入れすぎていないか（読者体験を優先）
- [ ] 著者・体験に基づく一次情報（E-A-T：専門性・権威性・信頼性）が明確か

**分析・改善**
- [ ] Google Analytics / Search Console が導入済みか、定期的に見ているか
- [ ] 一定期間（3〜6ヶ月目安）ごとにアクセス上位記事をリライトする運用を検討

## 4. まとめ記事（ハブ記事）という発想

- 特定テーマを絞った「まとめ記事」を作り、そこから詳細記事へ内部リンクを張る設計。
- ポイントは「リンク集ではなく、まとめ記事自体が読者の悩みに答える簡潔な内容になっていること」。
- テーマは広げすぎない（例：「子育て」ではなく「共働き家庭の時短家事」等に絞る）。

**chiyyy.comへの応用案**（実施前に運営者確認が必要）:
- 5カテゴリそれぞれに1本、そのカテゴリの入り口となる「まとめ記事」を用意し、既存記事へ内部リンクする。
- 特に「りべ大スタイル30記事シリーズ」（PR #34）は記事数が多いため、テーマ別のまとめ記事でグルーピングすると回遊率向上が見込める。

## 5. レビュー・体験談記事の型（今後アフィリエイトを検討する場合）

将来的に商品・サービス紹介記事を書く場合の型として：

1. 共感（読者の悩みを言語化）
2. 商品・サービスの簡単な紹介
3. 自身の体験談（実際に使った・利用した感想、良かった理由まで書く）
4. 客観情報（口コミ・レビューの補足）
5. メリット・デメリット（デメリットを先に書き、フォローを添えると信頼されやすい）
6. どんな人におすすめか
7. 今行動すべき理由（期間限定・実体験の後悔談など）

**注意**: アフィリエイト広告を掲載する場合は、景品表示法上のステルスマーケティング規制（広告であることの明示）に注意。また薬機法・医療系の表現（妊娠・出産・健康関連の記事は特に）には十分な確認が必要。この点は運営者自身の確認事項とする。

## 6. 継続のための心構え（運営方針として）

- 収益化までは半年〜1年程度かかるのが通常という前提を持つ。
- 目標（月◯万円）を先に決め、そこから逆算してタスクを細分化する。
- 完璧を目指さず、まず記事数を積み上げてから改善（リライト）する運用サイクルにする。
