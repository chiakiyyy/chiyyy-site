# chiyyy.com 記事スタイルガイド（あしらい・文章の作り方）

作成日: 2026-10-09
参照元: https://onimaga.jp/（名古屋散歩とシンプルライフのブログ）のページ構成・記事を複数閲覧し、
視覚表現（あしらい）と文章の構成を独自に分析・抽出したもの。文章・デザインの直接転用はしていない。

> 実装: `.info-box` / `.sub-label` のCSSは `src/pages/blog/[slug].astro` に定義済み（2026-10-09, PR #45）。

---

## 1. あしらいのルール

### 1-1. 小見出し（本文中の小項目）→ 左バー＋太字（色付きボックスにしない）

onimagaの「材料」「作り方」のような小見出しは、箱で囲まず「左に細いアクセントカラーのバー＋太字テキスト」で表現する。

```html
<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">見出しテキスト</span>
</div>

- 箇条書き1
- 箇条書き2
```

**使いどころ**: ルール・手順・料金表など、本文の途中に差し込む小さなまとまり。

### 1-2. 目次・まとめ → シンプルな枠線ボックス（色は使わない）

記事が長い・構造化されている場合のみ、冒頭に「CONTENTS」、末尾に「SUMMARY」のボックスを置く。短い日記・エッセイ系の記事には無理に入れない。

```html
<div class="info-box">
<p class="info-box-label">CONTENTS</p>
<p class="info-box-title">この記事でわかること</p>
<ul>
<li>見出し1</li>
<li>見出し2</li>
</ul>
</div>
```

ラベルは `CONTENTS` / `SUMMARY` のような英字小文字トラッキングの灰色テキストのみ。背景色・アクセントカラーの縁取りは使わない（onimagaの「CONTENTS」ボックスに合わせる）。

### 1-3. 画像配置

- セクションの節目（見出しの前後）に、実体験を裏付ける本物の写真を差し込む。フリー素材より説得力重視。
- 画像が無い場合は `<!-- 画像候補: ○○の写真 -->` の形でHTMLコメントを残す（表示には影響しない、後で埋める用のメモ）。
- 1記事に最低1枚（サムネイル）、理想は本文中にも2〜4枚。

### 1-4. アフィリエイト・商品紹介カードは対象外（既存デザインを維持）

本の紹介カード（書影＋タイトル＋価格＋「こんな人におすすめ」欄）、`AffCard`/`AffLink`/`PrNotice` のデザインは別途決定済みのため、本ガイドの対象外。**変更しない。**

紹介する商品・書籍のラインナップ自体は今後も入れ替わっていく前提（本は季節や文脈に応じて変わる、ASP案件も入れ替わる）。デザインの型だけを固定し、中身は都度差し替える。

### 1-5. 既存のまま維持するもの

- `<mark>` による強調（黄色・ピンク）
- 会話調・一人称のトーン
- H2見出しの下線スタイル

## 2. 文章の作り方

onimagaのエッセイ・日記記事から読み取った、読みやすさのための工夫：

- **段落は短く**：1段落2〜4文程度。改行をこまめに入れる（スマホでの読みやすさ重視）。
- **語尾は話し言葉**：「〜なんですよね」「〜だよなぁ」「〜かもな、なんて」など、素の独り言に近いトーン。ちーの既存記事のトーンとほぼ一致しているので、大きく変える必要はない。
- **レシピ・手順系の記事は構造化する**：材料→作り方のように、見出し＋箇条書き／番号付きリストで手順を分ける（1-1のsub-labelを使う）。
- **エッセイ系の記事は無理に構造化しない**：目次や箇条書きを無理に入れず、思考の流れをそのまま書いてよい。短めの記事では`info-box`（目次）も省略可。
- **連載ものは話数を入れてもよい**：onimagaは「第43話／全43話」のように連載記事に話数を振っている。chiyyy.comで連載的な企画をやる場合は参考にできる（現状は未導入）。

## 3. 適用方針

- 新規記事: `blog-post` スキルの手順に本ガイドの内容を統合済み（別PR）。
- 既存記事: 段階的に展開。1記事ずつ内容を確認しながら、`sub-label`/`info-box`/画像コメントを追加していく。
