## 「安い＝栄養がない」は誤解

野菜の栄養価は「値段」ではなく「種類」で決まります。有機野菜も通常の野菜も、ニンジンならビタミンAと食物繊維、ほうれん草なら鉄分とビタミンCの量はほぼ同じ。違うのは鮮度と見た目くらいなんだそうです。

たんぱく質も同じで、牛肉が100gあたり20gなのに対して、鶏むね肉は100gあたり21g。<mark>むしろ安い鶏むね肉の方が含有量は多い</mark>くらいなんですよね。「安い食材＝栄養がない」という思い込みが、無駄な食費を生んでいるのかもしれません。

## コスパの良い食材の選び方

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">たんぱく質が安い食材</span>
</div>

- 鶏むね肉：1kg500円程度
- 豆類（大豆・小豆）：1kg400円程度
- 卵：10個100円前後
- 牛乳：1L150円程度

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">ビタミン・ミネラルが安い食材</span>
</div>

- ほうれん草：1束100円（鉄分1日分）
- ニンジン：3本100円（ビタミンA豊富）
- タマネギ：3個100円
- バナナ：1本20〜30円（カリウム豊富）

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">穀類</span>
</div>

- 米：10kg3,000円程度（1膳20円程度）
- パスタ：500g100円程度
- オートミール：1kg400円程度

「良い食材」を選ぶコツは、ブランドではなく品目で選ぶこと、というのが調べてみての結論でした。

## 月3万円の食事例

家族4人（大人2人、子ども2人）、1週間7,500円を目安にすると、こんな内訳になります。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">たんぱく質源（週3,000円）</span>
</div>

鶏むね肉3kg、卵30個、豆製品（豆腐・納豆）、牛乳で合計3,000円程度。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">野菜・果物（週1,850円）</span>
</div>

ほうれん草、ニンジン、タマネギ、キャベツ、バナナ、その他旬の野菜を少しずつ。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">穀類・調味料（週1,500円）</span>
</div>

米、油・塩・醤油など、パスタ・パンで1,500円程度。

7,500円×4週＝30,000円。<mark>安い食材を選ぶというシンプルなルールだけで、月3万円は十分実現できそう</mark>でした。

## 子どもの栄養を守るポイント

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">良質なたんぱく質を毎日確保</span>
</div>

子どもの成長に欠かせないたんぱく質の目安は、1〜3歳で15g、4〜8歳で20g、9〜11歳で25g程度。鶏むね肉100g（約100円）で20g取れるので、コスパは申し分ないです。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">色々な野菜を少量ずつ</span>
</div>

栄養バランスに必要な野菜の種類は、実は5〜6種類で十分と言われています。緑（ほうれん草・ブロッコリー）、赤（トマト・ニンジン）、白（タマネギ・大根）、黄（トウモロコシ・バナナ）を少しずつ組み合わせるイメージです。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">加工食品はほどほどに</span>
</div>

外食やコンビニ食は便利だけど、家計にも栄養にもあまり優しくない。意識するだけで月3,000円くらいの削減になることもあるみたいです。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">週1回くらい食事を振り返る</span>
</div>

子どもの栄養が足りているか、たまに振り返るだけでも違います。毎日完璧じゃなくて大丈夫。

<mark>「子どものために高い食材を」より、「安い食材で栄養を確保する知識」の方が、長い目で見ると親の財産になる</mark>気がします。週3〜4日くらい手作りできれば十分で、完璧を目指さなくていいとも思います。
