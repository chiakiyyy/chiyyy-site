## キャリアと家計管理：どちらが大切？

実はこの2つ、同じくらい大事なんですよね。

- キャリア形成＝稼ぐ力を高めること
- 家計管理＝稼いだお金を活かすこと

どちらが欠けても、資産は増えません。

キャリアだけ頑張って年収を上げても、家計管理がずさんだと、給与が増えた分だけ支出も増えてしまう。いわゆる「ライフスタイルインフレーション」ってやつです。より高い家賃の物件に引っ越したり、外食やブランド品が増えたり。結果、手取りは増えても貯金額は変わらない、というケースをよく見ます。

逆に家計管理だけ頑張っても、年収が低いままだと資産形成には時間がかかるし、過度な節約はストレスになって長続きしません。

## 年収600万円でも貯金ゼロになる理由

周りにも年収600万円を超えている人はいますが、貯金がほぼない人も多いです。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">典型的な家計例（年収600万円・手取り約450万円）</span>
</div>

- 家賃：15万円/月
- 食費・日用雑貨：5万円/月
- 保険料：3万円/月
- 車費用：5万円/月
- 子どもの教育費：4万円/月
- 娯楽費・外食：5万円/月
- その他諸経費：2万円/月

合計支出は年間約468万円。手取り450万円から引くと<mark>年間18万円の赤字</mark>になる計算です。実際にはボーナスで補填している、というのが「年収600万円でも貯金ゼロ」の実態みたいです。

## 年収400万円でも資産が増える人の特徴

一方で、年収400万円でも着実に資産を増やしている人もいます。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">家計管理に強い人の特徴</span>
</div>

- 固定費を徹底的に削減している（家賃8万円程度、車を持たない、保険は最小限）
- 「何に人生でお金を使いたいか」の優先順位が明確
- 娯楽も工夫次第（無料レジャー活用、サブスクを厳選）

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">家計例（年収400万円・手取り約300万円）</span>
</div>

- 家賃：8万円/月
- 食費・日用雑貨：3万円/月
- 保険料：1.5万円/月
- 子どもの教育費：2万円/月
- 娯楽費・外食：1万円/月
- その他諸経費：1万円/月

合計支出は年間約198万円。手取り300万円から引くと<mark>年間102万円の黒字</mark>。同じ「年収」というものさしだけでは測れない差が、ここにあるんですよね。

## キャリア形成と家計管理を同時に進める方法

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">1. 現状把握</span>
</div>

年収と手取り、毎月の支出、実際に貯蓄できている額を正確に把握する。ここが曖昧だと何も始まりません。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">2. 優先順位を決める</span>
</div>

人生で大切なことは何か、その実現にはいくら必要か。5年後・10年後の目標を数値にしてみる。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">3. 家計最適化</span>
</div>

特に家賃・保険などの固定費を見直す。変動費の無駄も削減して、目標貯蓄額を設定する。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">4. キャリア戦略</span>
</div>

今のキャリアで年収が上がる見込みはあるか、転職の余地はあるか、スキルアップに投資すべきか考える。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">5. 資産運用を開始</span>
</div>

毎月の貯蓄が確保できたら、つみたてNISAなどで長期投資を始めて複利の力を活かす。

<mark>年収を上げるのには時間がかかるけど、家計を月5万円削減するのは今月からできる</mark>。すぐ動けるところから着手するのが近道だと思います。
