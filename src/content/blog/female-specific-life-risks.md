## サンドイッチ世代とは

上は高齢化する親の介護、下は子育て、そして自分たちの老後資金準備。この3つを同時に抱える状態を「サンドイッチ」に例えてそう呼ぶそうです。

親が要介護状態になる年齢は平均70代後半〜80代、子育て世代は平均25〜40代。つまり子育てがまだ必要な時期に、親の介護が重なってくる可能性があるということ。しかも日本では「介護は女性の責任」という社会的プレッシャーや、配偶者側の親の介護まで求められることも少なくなく、<mark>女性にとって親の介護は経済的な問題だけでなく人生の岐路になりうる</mark>んだなと感じました。

## 親の介護にかかる費用

要介護3程度を想定し、介護期間を5年とした場合でシミュレーションしてみます。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">自宅介護の場合（月額の目安）</span>
</div>

- 訪問介護：月8万円
- おむつ・衛生用品：月2万円
- その他医療費：月3万円

合計で月13万円程度。5年間だと13万円×12ヶ月×5年＝<mark>780万円</mark>という計算になります。入居型の介護施設だと月20〜30万円程度かかるケースもあるようです。780万円というと、子育てにかかる費用とほぼ同じくらいの規模感。しかも、これが子育てと同時に発生しうるというのが、調べていて一番びっくりした点でした。

## 親の介護がキャリアに与える影響

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">仕事を辞めて介護に専念</span>
</div>

親の世話に十分な時間を割けますが、収入はゼロになり、キャリアが中断されます。介護後の復職が難しくなることも多く、生涯年収への影響は小さくありません。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">仕事を続けながら介護</span>
</div>

収入とキャリアは維持できますが、仕事・育児・介護の「三重負荷」になりやすく、心身の健康を害するリスクも。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">親に施設入居してもらう</span>
</div>

心身の負担は減りますが、月20〜30万円の費用と、「十分に面倒を見られていない」という罪悪感がついて回ることもあるようです。

<mark>どの選択肢を選んでも、何らかのコストを払うことになる</mark>——これが現実なんだろうなと思います。

## 親の介護に備える方法

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">経済的な準備</span>
</div>

親が要介護状態になった時の費用負担を誰がするか、親の貯蓄や年金でどこまでカバーできるか、足りない分は兄弟姉妹でどう分担するか。早めに話し合っておきたいテーマです。子育て費用と同じくらい（800万円程度）を介護費の目安として、貯蓄計画に組み込んでおくのも一案です。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">キャリアの柔軟性を確保する</span>
</div>

リモートワーク可能な職種への転職、短時間勤務ができる環境づくり、副業による収入源の多元化など、介護が発生しても収入を維持できる体制を考えておく。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">兄弟姉妹との関係構築</span>
</div>

介護費用の分担や役割分担を事前に話し合っておく。「女性だから介護は当然」というプレッシャーに流されず、家族全体で分担する視点を持っておきたいところです。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">親の状況把握</span>
</div>

親の資産・貯蓄・年金額を事前に把握しておく、健康状態を定期的に確認する。[老後資金の計算](/blog/100-year-lifespan-planning/)と合わせて、親世代・自分世代両方のお金の見通しを立てておくと安心感が違います。
