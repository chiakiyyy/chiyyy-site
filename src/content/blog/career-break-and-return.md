## なぜキャリアは中断されるのか

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">物理的な時間制約</span>
</div>

子どもが小さい時期は、朝の保育園送迎、夜間の対応など、物理的に制限される時間が多い。どうしても労働時間を削減する必要が出てきます。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">精神的な優先順位の変化</span>
</div>

職場での責任ある業務よりも、子どもとの時間を重視したくなる。これは自然なことだと思います。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">企業側の評価基準の変化</span>
</div>

- 重要な業務は任せづらいと判断される
- すぐに休むリスクがあると見られる
- 今後の昇進が見込みにくくなる

これにより、異動や給与の据え置き、昇進の見送りが生じるケースが多いようです。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">キャリアの「空白期間」</span>
</div>

1〜2年の育休期間中、業界動向や職場の変化にキャッチアップできないまま時間が過ぎる。職場に戻った時には、すでにキャリアの段差が生まれている、というのはよく聞く話です。

<mark>キャリアの中断は「本人の努力不足」ではなく、社会構造の問題</mark>だよなと思います。

## 育休前後の年収比較

仮に、年収500万円の人がキャリア中断を経験したケースで考えてみます。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">昇進・昇給のない5年を過ごした場合</span>
</div>

- 1年目：年収500万円（復職、職位据え置き）
- 2〜5年目：給与凍結・昇給見送りが続き、490万円前後で横ばい

5年間の年収低下額は、年間10万円×5年＝50万円程度。

一方、育休がなく通常のキャリアを歩んでいたら、1年目500万円から毎年昇給して5年後には620万円になる、というシミュレーションもあります。

<mark>その差、年収130万円</mark>。同じ会社にいても、これだけの差が出うるというのは正直びっくりしました。

## 育休後の3つの復職パターン

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">① 同じ企業に復職（現状維持）</span>
</div>

勤続年数や福利厚生は継続できる一方、昇進・昇給が見送られがちで、キャリアの段差がそのまま放置されやすい。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">② 育休後に転職（キャリア再開）</span>
</div>

新しい職場では「育休経験者」として一から評価が始まり、年収交渉で育休前の年収を基準にできることも。ただし勤続年数はリセットされ、転職活動と育児の両立は大変です。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">③ フリーランス・個人事業主へ転換</span>
</div>

時間の自由度は一番高く、子育てと仕事のバランスを自分で決められる。その代わり安定性や社会保障は弱くなり、営業・事務など本業以外の負担も増えます。

どれが正解というより、<mark>人生の優先順位によって選ぶものが変わる</mark>んだと思います。

## キャリアの段差を埋める方法

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">育休中のスキル維持</span>
</div>

業界誌・ブログの購読、オンライン講座の受講、専門団体への所属継続など、育休中でも情報をキャッチアップしておくと復職後のギャップを減らせます。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">復職前の交渉</span>
</div>

育休前の年収をベースにした契約、段階的な復職スケジュール、キャリア開発の道筋など、復職のタイミングで交渉しておくと後々違ってくるようです。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">計画的な転職</span>
</div>

育休から1〜2年のタイミングでの転職は、キャリアの段差を埋める選択肢の一つ。育休前の経験・実績と、育児経験をポジティブに伝えることがポイントみたいです。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">副業・スキルアップへの投資</span>
</div>

資格取得や専門スキルの習得、副業による年収補填など、復職後の限られた時間でできることもあります。
