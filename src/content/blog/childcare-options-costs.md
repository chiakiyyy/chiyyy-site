こんにちは、ちいです！

子どもを持つと次に直面するのが「育児支援をどうするか」という選択。「保育園に預けるか」「親に見てもらうか」「自分で見るか」——この選択、その後の人生の質を結構左右する気がします。選択肢を費用とメリット・デメリットで整理してみました。

## 育児支援の選択肢

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">認可保育園（月0〜5万円程度）</span>
</div>

国の基準を満たした公的な保育施設。園庭があり、質の高い保育が期待できて、兄弟姉妹割引があることも多いです。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">認可外保育園・ベビーシッター（月10〜20万円程度）</span>
</div>

柔軟な対応が可能で個別対応が強みですが、質にばらつきがあります。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">祖父母に見てもらう（月0〜5万円程度・謝礼名目）</span>
</div>

費用は安く済みますが、頼る側の「負い目」や祖父母の身体的負担も考えておきたいところです。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">親が育休を取得（保育費用は不要、ただし給与が減る）</span>
</div>

子どもとの時間は最大化できますが、その分キャリアが中断され、経済的な負担は大きくなります。

<mark>それぞれにトレードオフがある</mark>んですよね。

## 各選択肢の年間費用

子ども1人（0〜3歳）、育児関連費が月3万円かかる前提で比較してみます。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">認可保育園利用（保育料月3万円の場合）</span>
</div>

年間費用は保育園代36万円＋育児関連費36万円＝72万円。親が年収500万円（手取り375万円）で働き続けられるので、残貯蓄可能額は年間約303万円という計算になります。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">祖父母に見てもらう場合</span>
</div>

謝礼月3万円＋育児関連費月3万円で、年間72万円。費用面では保育園とほぼ同じですが、親は働き続けられるのが特徴です。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">親が育休を取得する場合（1年間）</span>
</div>

育休中の給与は手取り月20万円程度（給与の60%）になるケースが多く、削減額は年240万円。育児関連費36万円を合わせると、実質的な負担は276万円ほどになります。

さらに復職後も、育児による残業削減で年収が50万円ほど下がったり、5年間のキャリア中断で昇進が見送られ150万円ほど影響が出ることも。<mark>育休は「費用がかからない」ように見えて、実は長期的な年収低下につながる</mark>、というのは[育休後の復職](/blog/career-break-and-return/)の記事でも書いた通りです。

## メリット・デメリット比較

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">認可保育園</span>
</div>

費用が安く、キャリアを継続でき、子どもの社会性も育ちやすい。一方で待機児童の問題や、子どもの急な発熱への対応は悩みどころです。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">祖父母サポート</span>
</div>

費用が安く、身内に見てもらえる安心感がある。ただし祖父母の身体的負担や、育児方針の違いによるトラブルも起こりえます。

<div class="sub-label">
<span class="sub-label-bar"></span>
<span class="sub-label-text">親の育休取得</span>
</div>

子どもとの時間を最大化できる一方、キャリアの中断と生涯年収への影響は大きく、親自身が孤立しやすいという声もよく聞きます。

## 長期的な人生設計での選択

家計を優先するなら保育園利用で年収を維持する道、子どもとの時間を優先するなら育休という道。そして、最初の1〜2年だけ育休を取って、その後は保育園に切り替える「バランス型」も現実的な選択肢の一つだと思います。

<mark>「親が見るのが当たり前」という思い込みにとらわれず、自分たちの優先順位で決めていい</mark>というのが、調べてみて一番感じたことです。
